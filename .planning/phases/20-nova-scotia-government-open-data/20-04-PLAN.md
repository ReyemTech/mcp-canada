<objective>
Implement Nova Scotia's environment / water / air-quality curated tools (NS-11, NS-12, NS-15, NS-16): surface water quality continuous monitoring, boil-water advisories, protected areas, and ambient air-quality monitoring stations.

CRITICAL quirks (resolved in the Wave 0 spike + 20-RESEARCH.md pitfalls):
- **Boil-water active filter (Pitfall 6, spike #2):** use the `ACTIVE_ADVISORY_FILTER` value pinned in 20-SPIKE.md / constants (NULL vs empty string for `date_advisory_removed`). An empty advisory list is a VALID off-season success — NOT an error (the Manitoba flood-alert lesson).
- **Geometry exclusion (Pitfall 5):** protected areas (ticv-5du5) has a MultiPolygon `the_geom`; the curated query MUST use explicit `$select` to exclude it. Live-test asserts `the_geom` NOT in rows (Plan 07).
- **Air quality is a stations catalog only:** individual pollutant time series live in 20+ separate per-station datasets — those are discovery-only via ns_query_dataset; document this in the docstring + the air-quality-guide resource (Plan 06).

Purpose: Round out the environment domain over the SODA client.
Output: 4 curated tools + client bodies + unit tests (incl. empty-advisory-is-valid + geometry-exclusion).
