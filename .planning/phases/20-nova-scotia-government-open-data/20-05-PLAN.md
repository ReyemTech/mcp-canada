<objective>
Implement Nova Scotia's health + demographics curated tools (NS-13, NS-14, NS-17): health facilities (hospitals + long-term care, dispatched), vital statistics, and chronic disease prevalence (dispatched by disease).

CRITICAL dispatch + normalization logic (from 20-RESEARCH.md + the Wave 0 spike):
- **Facility dispatch (NS-13):** `facility_type: Literal["hospital","long_term_care"]` selects tmfr-3h8a (hospitals) vs x76a-axw2 (LTC/RCF). Normalize both to a common shape so agents get one consistent facility schema. Invalid facility_type → INVALID_INPUT with `valid=` list (double-guard: tool + client ValueError).
- **Zone field normalization (Pitfall 7, spike #3):** the 5 chronic-disease datasets disagree (AMI uses `health_zone`, Diabetes uses `zone`). A `_normalize_zone_field` helper renames `health_zone`→`zone` per the spike's field map so every disease surfaces a consistent `zone`. Invalid disease → INVALID_INPUT with `valid=` list.
- **County UPPERCASE + year text (Pitfalls 3, 4):** vital stats (r794-fttm) county names are uppercase; year is text → string SoQL comparison. Document in the docstring.

Purpose: Complete the curated surface (12 curated tools total across Plans 03-05).
Output: 3 curated tools + client bodies + unit tests (incl. dispatch validation + zone normalization).
