<objective>
The federal-CKAN discovery surface — the five tools that let an agent find anything in New
Brunswick's 221-dataset corpus, plus the bilingual metadata resolution that makes NB the first
province in this rollout where `lang="fr"` returns genuinely French *content*, not just French
error strings (D-12).

New Brunswick has no provincial CKAN. `data.gnb.ca`, `opendata.gnb.ca` and `nbopendata.ca` do not
resolve. Discovery therefore runs against the **federal** catalogue at `open.canada.ca` filtered to
`organization:nb` (D-01), which is live-verified at 221 datasets. That filter is a security control
as much as a scoping one: if a caller could override it, a "New Brunswick" tool would silently
return NRCan federal basemaps (D-03 measured 906 such results for the naive free-text filter).

Purpose: give agents a complete, correctly-scoped, bilingual entry point into NB tabular data.
Output: 5 `nb_` discovery tools with unit coverage and an outgoing-param contract test.

**Validation note:** the spec-less probe fallback was skipped for this phase (no SPEC.md → no Edge
Coverage / Prohibitions to lift). Truths above derive from the CONTEXT.md `<domain>` boundary and
D-01/D-03/D-12.
</objective>
