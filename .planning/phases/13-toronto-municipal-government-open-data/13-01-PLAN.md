Use your judgment on whether Pydantic validation adds value for datastore records.

    1. Private helpers: _truncate, _limit_resources, _shape_resource (add datastore_active: bool to resource shape), _shape_dataset, _build_cache_key, _api_get — all identical to Ontario but with Toronto's BASE_URL and "toronto:" prefix.
    2. CKAN discovery functions (5): fetch_search_datasets, fetch_dataset_details, fetch_resource, fetch_organizations, fetch_dataset_count — identical signatures to Ontario.
    3. GTFS functions: fetch_gtfs_file(filename, ttl) downloads GTFS ZIP via GTFS_ZIP_URL, extracts the named .txt file using stdlib zipfile+BytesIO, parses with _parse_csv. Use timeout=120.0 for the 35.9 MB ZIP. fetch_gtfs_stops(query?) and fetch_gtfs_routes(route_type?) wrap fetch_gtfs_file with client-side filtering.
    4. Datastore helper: fetch_datastore_records(resource_id, filters?, limit, offset, fields?, sort?, cache_ttl) calls _api_get("action/datastore_search", ...). Returns result.get("records", []).
    5. Neighbourhood functions: fetch_neighbourhood_profile(neighbourhood?, characteristic?, limit) and fetch_neighbourhood_comparison(characteristic, limit) — both call fetch_datastore_records with NEIGHBOURHOOD_PROFILES_RESOURCE_ID and appropriate filters/queries. NOTE: The 2016 profile resource is indicator-per-row with neighbourhood names as columns. For the profile tool, use datastore_search with q=characteristic to filter rows; return all columns. For comparison, same approach — filter by Characteristic value, return the row which has all neighbourhood values.
    6. 311 function: fetch_311_requests(year, ward?, service_type?, status?, limit) — first calls fetch_dataset_details("311-service-requests-customer-initiated") to discover the ZIP URL for the given year, then downloads and parses the ZIP>CSV, applies client-side filters. Cache parsed rows keyed by year.
    7. Housing functions: fetch_rentsafe_evaluations(ward?, min_score?, limit) calls fetch_datastore_records with RENTSAFE_EVAL_RESOURCE_ID, applies min_score filter client-side. fetch_short_term_rentals(ward?, status?, limit) calls fetch_datastore_records with SHORT_TERM_RENTALS_RESOURCE_ID.
