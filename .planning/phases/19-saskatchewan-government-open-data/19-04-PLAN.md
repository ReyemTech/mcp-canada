<objective>
Implement Saskatchewan's environment domain — 3 curated tools (SK-10, SK-11, SK-12): current fire bans (SPSA), historic wildfire boundaries, and live ambient air quality. Health is deferred (no public SHA FeatureServer); air quality is the substituted 3rd environment tool keeping the curated count at target.

The fire-ban tool is the one architectural wrinkle: SPSA's Public_Fire_Ban is on a SEPARATE ArcGIS REST server (gis.saskatchewan.ca/egis), not the primary Hub org — it uses FIRE_BAN_FS_URL directly with the FIRE_BAN_LAYERS dispatch, and an empty list in the off-season is a VALID success (same as Manitoba flood alerts), never an error.

Purpose: Parity environment coverage; fire bans and air quality are time-sensitive, agent-valuable live data.
Output: 3 curated tools + client bodies + unit tests.
</objective>
