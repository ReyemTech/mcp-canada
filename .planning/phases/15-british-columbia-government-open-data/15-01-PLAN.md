Verified WFS parameter rules (RESEARCH.md §WFS 2.0 Protocol Essentials):
- service=WFS, version=2.0.0, request=GetFeature
- typeNames (PLURAL — WFS 2.0 spec). Never send typeName (singular).
- outputFormat=application/json
- count, startIndex, sortBy=OBJECTID, srsName=EPSG:4326
- Optional: CQL_FILTER, BBOX, propertyName, resultType=hits (for count only)
- Error detection: status 400 + content-type containing "xml" -> parse ows:ExceptionReport
