    GREEN phase — implement tools.py:

    All 6 tools use standalone `@tool` from `fastmcp.tools.tool`. Module prefix: `ds_`.

    Each tool unwraps the `(data, was_cached)` tuple from client functions:
    ```python
    data, was_cached = await client.create_table(table_name, col_tuples)
    return make_response({"table": table_name, "columns": len(col_tuples)}, api_name="datastore", cached=was_cached, lang=lang)
    ```

    **ds_create_table(table_name: str, columns: list[dict] | None = None, data: list[dict] | None = None, lang: Literal["en", "fr"] = "en")**
    - If `columns` provided: validate and create with explicit schema
    - If `columns` is None and `data` provided: infer types from first row using _infer_sqlite_type
    - If neither: return make_error
    - Unwraps `(None, False)` from client.create_table()
    - Returns make_response with table name and column count, api_name="datastore", cached=was_cached

    **ds_insert_data(table_name: str, rows: list[dict], lang: Literal["en", "fr"] = "en")**
    - Unwraps `(row_count, False)` from client.insert_rows()
    - Returns make_response with row count inserted

    **ds_query(sql: str, lang: Literal["en", "fr"] = "en")**
    - Unwraps `((columns, rows, truncated), False)` from client.run_query()
    - Returns make_response with QueryResult data (columns, rows, row_count, truncated)

    **ds_list_tables(lang: Literal["en", "fr"] = "en")**
    - Unwraps `(table_names, False)` from client.list_tables()
    - Returns make_response with list of table names and count

    **ds_get_schema(table_name: str, lang: Literal["en", "fr"] = "en")**
    - Unwraps `(column_info, False)` from client.get_schema()
    - Returns make_response with column definitions

    **ds_drop_table(table_name: str, lang: Literal["en", "fr"] = "en")**
    - Unwraps `(None, False)` from client.drop_table()
    - Returns make_response confirming table dropped

    Each tool catches ValueError from _validate_identifier and returns make_error("INVALID_INPUT", str(exc), lang=lang). Other exceptions caught as make_error("DATASTORE_ERROR", str(exc), lang=lang).

    Docstring format (enforced by test_quality.py):

    ```
    Use for: creating tables to store data from any source, setting up structured storage
    Keywords: datastore, create, table, sqlite, store, persist, schema, columns
    """
    ```

    Minimum 8 keywords per tool. Keywords should include: datastore, sqlite, store, persist, and tool-specific terms.
