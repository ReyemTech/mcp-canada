<objective>
Implement the 4 AER (Alberta Energy Regulator) tools that surface Alberta's signature energy data — well licences (daily + monthly archive), pipeline statistics (annual ST39), and production volumes (monthly ST3 for 7 products). All tools fetch from `https://static.aer.ca/prd/...` static URLs using the existing `shared/parsers.fetch_and_parse()` helper. NO `shared/aer.py` extraction (research § "AER Source-of-Truth Policy" — premature abstraction).

Purpose: Alberta's distinguishing data asset is its energy sector. These 4 tools deliver the well/pipeline/production data agents will most often query for Alberta. ST57 incidents intentionally deferred (PDF-only since 2014, Pitfall 7).

Output: 4 working AER tools with conservative rate-limiting (2 r/s) and appropriate cache TTLs (DAILY=1h, MONTHLY=24h, ANNUAL=7d).

       ```python
       def _parse_st1_txt(text: str) -> list[dict]:
           """Parse AER ST1 fixed-width well-licence TXT.

           Skips header lines (first 6-7 rows of preamble). Each data row's columns
           are at fixed character positions documented in the AER ST1 manual.
           """
           rows = []
           lines = text.splitlines()
           # Find data start: first line whose first chars are a digit (licence number)
           data_start = next(
               (i for i, ln in enumerate(lines) if ln[:7].strip().isdigit()),
               len(lines)
           )
           for line in lines[data_start:]:
               if len(line) < 80:  # skip footers / blanks
                   continue
               rows.append({
                   "licence_number": line[0:10].strip(),
                   "well_name": line[10:50].strip(),
                   "operator": line[50:90].strip(),
                   "location": line[90:130].strip(),
                   "spud_date": line[130:140].strip() or None,
                   "status": line[140:160].strip() or None,
                   "surface_uwi": line[160:200].strip() or None,
               })
           return rows
       ```
       Adjust column ranges if real AER ST1 file inspection during implementation reveals different positions. The key is: snake_case field names, strings only, None for blanks.

    2. `fetch_well_licences_today()`:
       ```python
       import datetime
       async def fetch_well_licences_today() -> tuple[list[dict], bool]:
           today_abbr = DAY_ABBR[datetime.date.today().weekday()]
           url = f"{AER_ST1_DAILY_BASE}/WELLS{today_abbr}.TXT"
           cache_key = f"{CACHE_KEY_PREFIX}aer_st1_daily:{today_abbr}"
           limiter = get_limiter(RATE_GROUP_AER, RATE_LIMIT_AER)

           async def _fetch():
               await limiter.acquire()
               async with httpx.AsyncClient(follow_redirects=True, timeout=30) as ac:
                   resp = await ac.get(url, headers={"User-Agent": USER_AGENT})
                   resp.raise_for_status()
                   return _parse_st1_txt(resp.text)

           return await cached_fetch(cache_key, CACHE_TTL_DAILY, _fetch)
       ```

    3. `fetch_well_licences_archive(year: int, month: int)`:
       ```python
       async def fetch_well_licences_archive(year: int, month: int) -> tuple[dict, bool]:
           url = f"{AER_ST1_MONTHLY_BASE}/dwll{year}-{month:02d}.zip"
           cache_key = f"{CACHE_KEY_PREFIX}aer_st1_archive:{year}-{month:02d}"
           # Discovery-only: do NOT auto-fetch the ZIP (large fixed-width content)
           result = {"url": url, "year": year, "month": month,

           return result, False  # never cached (just metadata construction)
       ```

       async def fetch_pipeline_statistics(year: int) -> tuple[list[dict], bool]:
           url = f"{AER_ST39_BASE}/ST39-{year}.xls"
           cache_key = f"{CACHE_KEY_PREFIX}aer_st39:{year}"
           limiter = get_limiter(RATE_GROUP_AER, RATE_LIMIT_AER)
