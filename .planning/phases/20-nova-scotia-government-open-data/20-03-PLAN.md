<objective>
Implement Nova Scotia's signature domain — fishing/aquaculture (NS-07…NS-10) — the 4 curated tools that distinguish the NS module: marine aquaculture leases, landbased aquaculture licenses, fish hatchery stocking records, and aquaculture production/value/employment.

CRITICAL Socrata quirks baked in from the first commit (from 20-RESEARCH.md pitfalls):
- **Geometry exclusion (Pitfall 5):** marine leases (h57h-p9mm) carries a MultiPolygon `the_geom` that bloats responses. Every curated query MUST use an explicit `$select` listing the attribute columns so `the_geom` is excluded. Live-test asserts `the_geom` NOT in flattened rows (Plan 07).
- **Year is text (Pitfall 3):** production (v2ex-ev63) year filtering uses quoted string comparison (`$where=year='2020'`).
- **County casing (Pitfall 4):** document the stored casing per dataset; do not silently lowercase.

Purpose: Ship the highest-value, agent-friendly NS datasets through the SODA client built in Wave 0.
Output: 4 curated tools + client bodies + unit tests asserting $select/geometry-exclusion + filter behavior.
</objective>
