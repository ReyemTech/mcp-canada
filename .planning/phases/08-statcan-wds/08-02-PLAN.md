  <action>
    Add 4 client functions to `client.py`:

    1. **`get_data_by_ref_period(vector_id: int, start_date: str, end_date: str) -> tuple[list[ObservationRow], bool]`**:
       - GET to `BASE_URL + "getDataFromVectorByReferencePeriodRange"` — this endpoint uses query params, not POST body
       - Params: build manually as `vectorIds={vector_id}&startRefPeriod={start_date}&endReferencePeriod={end_date}` (the endpoint expects vectorIds without quotes for single vector)
       - If httpx params serialization doesn't work correctly for this endpoint, construct the URL manually
       - `_unwrap()`, extract vectorDataPoint, flatten to ObservationRow list, sort newest-first
       - Cache key: `statcan_wds:getDataFromVectorByReferencePeriodRange:{vector_id}:{start_date}:{end_date}`, TTL: CACHE_TTL_OBS

    2. **`get_bulk_vector_data(vector_ids: list[int], start_release: str, end_release: str) -> tuple[dict[int, list[ObservationRow]], bool]`**:
       - POST to `BASE_URL + "getBulkVectorDataByRange"` with body `{"vectorIds": [str(v) for v in vector_ids], "startDataPointReleaseDate": start_release, "endDataPointReleaseDate": end_release}`
       - Note: vectorIds must be strings for this endpoint (per WDS spec)
       - Response is a list of `{status, object}` per vector — iterate all items
       - For each SUCCESS item: extract vectorDataPoint, flatten observations, add to result dict keyed by vectorId
       - For FAILED items: collect into a warnings list (do NOT silently drop)
       - Return `({vector_id: [ObservationRow, ...]}, was_cached)` — caller can check if any vectors missing
       - Cache key: `statcan_wds:getBulkVectorDataByRange:{sorted_ids}:{start_release}:{end_release}`, TTL: CACHE_TTL_OBS

    3. **`get_changed_series() -> tuple[list[dict], bool]`**:
       - GET to `BASE_URL + "getChangedSeriesList"` — no params
       - `_unwrap()`, return list of dicts with keys: vectorId, productId, coordinate, releaseTime
       - Cache key: `statcan_wds:getChangedSeriesList`, TTL: CACHE_TTL_OBS

    4. **`get_changed_cubes(date: str) -> tuple[list[dict], bool]`**:
       - GET to `BASE_URL + f"getChangedCubeList/{date}"`
       - `_unwrap()`, return list of dicts with keys: productId, releaseTime
       - Cache key: `statcan_wds:getChangedCubeList:{date}`, TTL: CACHE_TTL_OBS
