# Plan 20.1-04: De-mask York Region + Alberta

Two more real bugs, one in shared code.

## Bug 3 — every ArcGIS Hub "list everything" call was broken

`shared/arcgis_hub.py` sent `q=` on no-query listings. All five portals tested
(aurora, newmarket, york_region, markham, manitoba) return **HTTP 400 for an
empty q and 200 when it is omitted**. aurora_list_categories and
newmarket_search_datasets returned UPSTREAM_ERROR, reading as an outage. Fix
reaches York Region, Alberta, Manitoba and Saskatchewan.

## Bug 4 — York Region text filters were case-sensitive against uppercase data

`STREET LIKE '%Main%'` matched 0 rows; `UPPER(STREET) LIKE '%MAIN%'` matched 420.
An agent asking for "Main Street in Markham" got an empty result. Fixed all
three LIKE filters; three unit tests that encoded the defect were updated.

## Shape drift (D-05)
York Region returns `{features, count, truncated}` — the same convention BC WFS
and all four ArcGIS modules use. The dict is deliberate; the tests were wrong.
