<objective>
The GeoNB surface opens here: three discovery tools that replace the unavailable ArcGIS Hub Search
API, plus New Brunswick's signature data domain — flood and water.

GeoNB is a bare ArcGIS Server. There is no catalogue API in front of it: the Hub at
`geonb-snb.opendata.arcgis.com` returns HTTP 401 `"private org id ... is not accessible"`. The two
functions added to `shared/arcgis_hub.py` in Wave 0 walk the REST directory instead, and this plan
puts them behind agent-callable tools. That trio is what makes D-07's curation bar defensible: 11
services are curated, the other 51 stay reachable.

Flood is NB's signature domain — the Saint John River is why. Four curated tools land here, each
pinned to a layer id resolved live in `21-SPIKE.md`, never assumed. Crown Land already proved in the
Wave 0 tracer that layer 0 is not a safe default (its only layer is 3); Wetlands is layer 2.

Purpose: make GeoNB navigable and ship NB's most distinctive data.
Output: 7 tools with unit coverage, one of them guarding a 163,206-record layer.

**Validation note:** the spec-less probe fallback was skipped for this phase (no SPEC.md). Truths
derive from the CONTEXT.md `<domain>` boundary, D-02/D-06/D-07 and 21-RESEARCH.md.
</objective>
