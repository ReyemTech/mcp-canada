    2. Write failing tests in `src/mcp_canada/shared/__tests__/test_parsers.py`. Use synthetic XLSX bytes created via openpyxl in fixtures (create a minimal workbook in memory, save to BytesIO, read .getvalue()). For CSV tests, use plain string bytes.     3. Create `src/mcp_canada/shared/parsers.py` implementing:
       - `_normalize_key(header: str) -> str`: regex replace non-alphanumeric with underscore, collapse multiple underscores, strip, lowercase, prefix "col_" if starts with digit, fallback "col" if empty
       - `_mask_privacy(value: Any) -> Any`: if isinstance str and strip() == '--' return None, else return value
       - `_parse_xlsx(content: bytes, sheet: str | int = 0, skip_rows: int = 0) -> list[dict]`: use openpyxl load_workbook(BytesIO(content), read_only=True, data_only=True), try/finally wb.close(), extract headers from first row after skip_rows, build list[dict] with _normalize_key and _mask_privacy
       - `_parse_csv(content: bytes, skip_rows: int = 0) -> list[dict]`: decode with utf-8-sig, csv.DictReader, apply _normalize_key and _mask_privacy. Note: skip_rows for CSV skips lines before passing to DictReader (skip metadata lines before header)
       - `_parse_xls(content: bytes, sheet: str | int = 0, skip_rows: int = 0) -> list[dict]`: try importing xlrd, if unavailable raise ImportError with message "Install xlrd for .xls support: pip install mcp-canada[ircc]". If xlrd available, use xlrd.open_workbook(file_contents=content) to parse
       - `async def fetch_and_parse(url: str, sheet: str | int = 0, skip_rows: int = 0, ttl: int = 86400) -> tuple[list[dict], bool]`: build cache_key from url+sheet+skip_rows, define inner async _fetch() that uses httpx.AsyncClient(timeout=60.0) to GET url and route to correct parser by URL suffix (.csv -> _parse_csv, .xls -> _parse_xls, else -> _parse_xlsx). Return via cached_fetch(cache_key, ttl, _fetch).

    IMPORTANT: Do NOT use the shared api_get() — it calls .json() on the response. Use httpx.AsyncClient directly and read .content (bytes).
    IMPORTANT: openpyxl workbook must be closed in try/finally, NOT context manager.
    IMPORTANT: Let exceptions propagate from _fetch() — never return [] on error. cached_fetch should NOT cache errors.
