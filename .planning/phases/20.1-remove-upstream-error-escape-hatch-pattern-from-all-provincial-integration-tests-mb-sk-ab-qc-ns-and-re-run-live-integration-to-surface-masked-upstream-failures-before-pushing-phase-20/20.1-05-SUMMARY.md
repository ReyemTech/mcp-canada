## Bug 5 — coordinate with no series crashed on Pydantic validation
responseStatusCode 2 with all-null fields reached SeriesInfo and surfaced as
"UPSTREAM_ERROR: 6 validation errors". Now a clean NOT_FOUND.

## Bug 6 — empty SDMX results are malformed JSON, blamed on the caller
StatCan emits two surplus closing braces for an empty result. JSONDecodeError
subclasses ValueError and was caught by the handler meant for parameter
conflicts, producing "INVALID_INPUT: Expecting ',' delimiter".

## Bug 7 — both TTC tools were dead, not flaky
The pinned dataset uuid, resource uuid and filename all 404 after a Toronto
republish. Resolved from CKAN by SLUG at call time. Live check after fix: 9,361
stops. **This is exactly what D-09 was written to prevent** — the hardened
pattern alone would have marked a dead tool green forever.

## Bug 8 — the datastore refused nested values
"Error binding parameter 2: type 'dict' is not supported". IRCC nests by design
and the datastore exists for cross-module SQL, so nested values are now stored
as JSON text and stay queryable via json_extract().
