# Plan 20.1-01: Masking guard + PRESERVE marker

One rule: every path through an integration test must reach an assertion.
Three structural violations detected — one-armed `if` on the response, bare
`return`, and `pytest.skip`. The hardened pattern satisfies the rule by
construction and needs no exemption.

Initial scan found **62 violations across 7 files**, well above the 27 a grep
had suggested, because the AST also sees nested one-armed guards.

The detector is itself tested with 6 parametrized cases (hardened pattern must
NOT flag; conditional over local bookkeeping must NOT flag). Two meta-tests keep
exemptions honest: a mandatory non-trivial reason, and a 10% ceiling.

`tolerates_upstream_error(reason)` registered in pyproject.
