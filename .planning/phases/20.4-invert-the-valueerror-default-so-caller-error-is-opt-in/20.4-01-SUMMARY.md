# Plan 20.4-01: Invert the ValueError default

## What shipped

`shared/errors.py` with `InvalidInput` → `INVALID_INPUT`, `NotFound` →
`NOT_FOUND`, `UpstreamData` → `UPSTREAM_ERROR`. A plain `ValueError` now defaults
to `UPSTREAM_ERROR`, so an unrecognised subclass is classified safely with no
code change. 31 raises classified, 35 arms flipped, 10 sniffing arms deleted,
13 stale tests updated.

## Nine live misclassifications fixed

Not only future-proofing — these returned the wrong code to agents:
`"Dataset not found"` (manitoba ×2, saskatchewan ×2, york_region) was
`INVALID_INPUT`, now `NOT_FOUND`; `"StatCan returned empty response body"`,
`"WDS request failed"` and `"SDMX returned an unparseable body"` now
`UPSTREAM_ERROR`; `"portal has no public ArcGIS Hub open data portal"` now
`NOT_FOUND`.

## Codex review (PR #5) — finding valid, re-review clean

york_region's `_call_client` dropped `NotFound` into its generic
`except Exception`, so a routine missing dataset read as an upstream outage.
Those 28 tools carry no `@upstream_guard` — 20.2 skipped them precisely because
that helper was already a catch-all — so they never got the central marker
mapping. Marker arms now come first. Codex re-reviewed `777fa44` clean.

## Two bad measurements caught before they became claims

- **A marker audit reported 118 mishandlings.** Wrong: the probe passed junk
  arguments (`station="x"`) that trip each tool's own validation before the mock
  is reached. Real count, restricted to paths that can occur: **zero**.
- **The live run appeared to take 26 minutes**, resembling the Drug/Nutrient
  stall retired in 20.3. pytest self-reported 173.51s — the gap was concurrent
  `uv run` commands holding the environment lock. Verified before amending two
  verification reports on a false premise.

## Standing lesson

Four phases each fixed a symptom in one place and generalised without checking
the neighbours. What broke the cycle was not more care but a test asserting a
*property* — `test_unknown_valueerror_subclass_defaults_to_upstream` defines a
novel subclass and asserts it cannot be blamed on the caller. One assertion over
the open set, instead of a list of the three subclasses found so far.
