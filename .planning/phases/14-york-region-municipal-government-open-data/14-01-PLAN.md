    ```python
    MAX_RECORDS = 5000           # cap per tool call — prevents runaway pagination
    DEFAULT_PAGE_SIZE = 1000     # safe default; actual maxRecordCount varies 1000-2000
    HUB_SEARCH_PATH = "/api/search/v1/collections/all/items"
    DEFAULT_TIMEOUT = 30.0
    ```

    **Public functions (bare async, NO cached_fetch/get_limiter — those wrap this from client.py):**

    1. `async def search_hub_datasets(portal_base_url: str | None, query: str = "", limit: int = 10, offset: int = 0, *, httpx_client: httpx.AsyncClient | None = None) -> dict`
       - Raises ValueError("portal has no public ArcGIS Hub") if portal_base_url is None
       - Builds params: {"q": query, "limit": limit}; adds offset only if > 0
       - Empty query allowed — returns all items
       - Uses provided httpx_client or creates a new AsyncClient() with DEFAULT_TIMEOUT
       - Returns raw JSON dict (contains numberMatched, numberReturned, features[], links[])
       - Raises httpx.HTTPStatusError on 4xx/5xx

    2. `async def query_feature_service(service_url: str, layer_id: int, where: str = "1=1", out_fields: str = "*", include_geometry: bool = False, max_records: int = MAX_RECORDS, *, httpx_client: httpx.AsyncClient | None = None) -> tuple[list[dict[str, Any]], bool]`
       - Build the per-page URL `{service_url}/{layer_id}/query` with params: where, outFields, f="geojson", resultOffset=offset, resultRecordCount=min(DEFAULT_PAGE_SIZE, max_records - offset)
       - Loop while offset < max_records. On each iteration: parse raw JSON, extract features via `_parse_geojson(response.content, include_geometry=include_geometry)`, extend accumulator list, check `raw.get("exceededTransferLimit", False)`. Break on False. Otherwise increment offset by batch length.
       - If loop exits because `offset >= max_records` and exceededTransferLimit is still True on the last page, set truncated=True.
       - Return (features, truncated)

    3. `async def get_layer_metadata(service_url: str, layer_id: int, *, httpx_client: httpx.AsyncClient | None = None) -> dict[str, Any]`
       - GET `{service_url}/{layer_id}?f=json`, return {"max_record_count": int, "fields": [{name, type}], "geometry_type": str | None, "name": str}

    4. `async def get_count(service_url: str, layer_id: int, where: str = "1=1", *, httpx_client: httpx.AsyncClient | None = None) -> int`
       - GET `{service_url}/{layer_id}/query` with params {where, returnCountOnly: "true", f: "json"}
       - Return int(data.get("count", 0))

    5. `def shape_hub_dataset(feature: dict[str, Any]) -> dict[str, Any]`
       - Private-style helper that flattens a single Hub Search `features[i]` entry
       - Extract from feature.properties: title, type, description (truncated to MAX_DESCRIPTION_CHARS=500), url, owner, tags (list), categories (list), created, modified
       - Add id from feature.get("id") if present
       - Return flat dict

    **Error handling:** Let httpx.HTTPStatusError propagate. Callers (module-level client.py) wrap with their own try/except.

    ```python
    class NoPortalError(Exception):
        """Raised when a municipality has no public ArcGIS Hub portal."""


    def _require_portal(portal_key: str) -> str:
        url = PORTAL_URLS.get(portal_key)
        if url is None:
            raise NoPortalError(
                f"{portal_key} has no public ArcGIS Hub open data portal as of 2026-04"
            )
        return url


    async def _rate_limited_call(coro_factory):
        """Acquire rate limiter then invoke the zero-arg coroutine factory."""
        limiter = get_limiter(RATE_GROUP, RATE_LIMIT)
        await limiter.acquire()
        return await coro_factory()
    ```
