Implement the 5 ArcGIS Hub discovery tools (SK-01…SK-05) — the same shape as Manitoba Phase 18 and Alberta Phase 17. These are the entry point for everything not curated: agents search geohub.saskatchewan.ca, get dataset details (incl. FeatureServer URLs), and query any dataset via the auto-router.

Purpose: Establish the Hub discovery surface and fill TestSharedApiGetContract so the parsed-dict contract is enforced from the first wave.
