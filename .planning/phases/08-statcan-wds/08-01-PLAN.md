  <action>
    Expand `client.py` with three public client functions:

    1. **BM25 search infrastructure** — private functions:
       - `_bm25_score(query_terms, doc_tokens, avg_dl, N, df) -> float`: Okapi BM25 with k1=1.2, b=0.75. Uses `math.log` for IDF, `collections.Counter` for TF.
       - `_build_doc_tokens(cube: dict) -> list[str]`: tokenize cubeTitleEn + cubeTitleFr + subjectCode + surveyCode, lowercase, split on whitespace.
       - `_build_search_index(cubes: list[dict]) -> tuple[list[dict], float, dict[str, int]]`: compute avg_dl and per-term document frequency dict over all cubes. Return (cubes, avg_dl, df).

    2. **`search_cubes(query: str, limit: int = 10) -> tuple[list[CubeLite], bool]`**:
       - Use `cached_fetch("statcan_wds:getAllCubesListLite", CACHE_TTL_CUBES, fetcher)` where fetcher calls GET `BASE_URL + "getAllCubesListLite"` via `_make_statcan_client()` with `await limiter.acquire()`.
       - After fetching, call `_build_search_index(cubes)` and store `(cubes, avg_dl, df)` as the cached value.
       - On cache hit, unpack `(cubes, avg_dl, df)` from cached value.
       - Tokenize query (lowercase split), score all cubes via `_bm25_score`, sort descending, take top `limit`.
       - Flatten each result to `CubeLite` using `FREQUENCY_CODES` for frequency decoding.
       - Return `(results, was_cached)`.

    3. **`get_cube_metadata(product_id: int) -> tuple[CubeMetadata, bool]`**:
       - Cache key: `statcan_wds:getCubeMetadata:{product_id}`
       - POST to `BASE_URL + "getCubeMetadata"` with JSON `[{"productId": product_id}]`
       - Use `_unwrap()` on response, flatten to `CubeMetadata` schema
       - Decode `frequencyCode` using `FREQUENCY_CODES`
       - Cache with `CACHE_TTL_META` (24hr)

    4. **`get_code_sets() -> tuple[CodeSets, bool]`**:
       - Cache key: `statcan_wds:getCodeSets`
       - GET `BASE_URL + "getCodeSets"`
       - Use `_unwrap()`, flatten each category to `list[CodeSetEntry]`, return `CodeSets`
       - Cache with `CACHE_TTL_CODESETS` (7d)

    All functions use `get_limiter(RATE_GROUP, rate=RATE_LIMIT)` and `_make_statcan_client()` as context manager inside the fetcher closure. All follow the `(data, was_cached)` return convention.

    Write RED tests first using mocked HTTP (patch `httpx.AsyncClient`) and fixtures from conftest.py. Verify cache key, TTL, limiter.acquire() calls via mock assertions.
