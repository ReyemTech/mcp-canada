**Example 20: CPI + BoC Rates**
Prompt: "Did rate hikes slow inflation? Show me CPI alongside the Bank of Canada policy rate."
APIs: Statistics Canada + Bank of Canada + Datastore
Steps:
1. sc_get_data_by_vector(vector_id=41690973, n=24) -- CPI all-items monthly
2. sc_fetch_vectors_to_store(vector_ids=[41690973], start_release="2023-01-01", end_release="2024-12-31", table_name="cpi_data")
3. boc_get_interest_rates(rate_type="policy", start_date="2023-01-01", end_date="2024-12-31")
4. ds_create_table(table_name="boc_rates", columns=[{name: "date", type: "TEXT"}, {name: "rate", type: "REAL"}])
5. ds_insert_data(table_name="boc_rates", rows=[...from step 3...])
6. ds_query(sql="SELECT c.ref_per, c.value AS cpi, b.rate AS policy_rate FROM cpi_data c JOIN boc_rates b ON c.ref_per = b.date ORDER BY c.ref_per")
Insight: The agent maps rate hikes against CPI movement month-by-month, revealing the lag between monetary tightening and inflation response.

**Example 21: GDP + Exchange Rate**
Prompt: "How does GDP growth correlate with the Canadian dollar? Show me GDP by province alongside CAD/USD."
APIs: Statistics Canada + Bank of Canada + Datastore
Steps: Fetch GDP table (36100434) via sc_get_sdmx_data, store to datastore, fetch USD/CAD from BoC, store, JOIN on date.
Insight: Export-heavy provinces show tighter currency correlation than service economies.

**Example 22: Labour + Weather**
Prompt: "Does growing season weather affect agricultural employment? Compare seasonal employment with growing degree days."
APIs: Statistics Canada + Weather + Datastore
Steps: Fetch employment data (14100355) via sc_get_data_by_vector, store. Fetch climate normals via wx_get_climate_normals for agricultural station. Store. SQL query comparing seasonal patterns.
Insight: Agricultural employment peaks 6-8 weeks after temperature thresholds, visible when both datasets sit in one queryable store.

**Example 23: Population + Parliament**

APIs: Statistics Canada + Open Parliament + Datastore
Steps: Fetch population data via StatCan, store. Search housing bills via parl_search_bills. Get voting records. Store MP votes. SQL JOIN riding population growth with voting patterns.
Insight: MPs from high-growth ridings are more likely to vote for housing supply bills regardless of party, quantifiable when demographic and legislative data share a table.
